# 🎓 "Protekt" Security Alarm Project
📍 **University of Aveiro**  
🏆 **Grade: 20/20** 

This project involved developing a basic security alarm system using an STM32 Nucleo-F411RE microcontroller. The system detects motion through a PIR sensor and activates a buzzer when movement is detected. It also supports RFID-based arming and disarming, allowing contactless user control.
